# Security policy

## Supported versions

The current developer alpha is the only actively supported line:

| Version | Supported |
|---|---|
| 0.1.0a1 | Yes |
| Earlier development snapshots | No |

## Reporting a vulnerability

Do not disclose a suspected security issue in a public discussion before the
maintainer has had a reasonable opportunity to investigate it. Once the GitHub
repository enables private vulnerability reporting, use that channel. Until
then, contact the project owner through the private contact method listed on
the repository profile.

A useful report includes:

- affected version;
- operating system and Python version;
- minimal reproduction steps;
- potential impact;
- whether the issue affects source checkout, wheel installation, or both.

This policy covers software-security issues. Scientific-model limitations and
numerical inaccuracies should be reported as ordinary bugs unless they create
a software-security impact.
