# Licensing decision for the developer alpha

**Selected license: `Apache-2.0`**

Apache-2.0 is the selected license for the iQuant4 developer alpha. It is a permissive license with an explicit contributor patent grant and patent-termination provisions. This choice is intended to support research collaboration, external contributions, and commercial adoption while preserving attribution and the license terms.

The authoritative terms are in the root [`LICENSE`](../../LICENSE) file and the SPDX expression in `pyproject.toml`. This document records the technical and project rationale; it is not legal advice.
