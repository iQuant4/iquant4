# iQuant4 Community Code of Conduct

The iQuant4 community is committed to a respectful, rigorous, and welcoming
technical environment.

## Expected conduct

Participants should:

- discuss scientific and engineering disagreements with evidence and respect;
- give actionable feedback without personal attacks;
- acknowledge uncertainty, limitations, and prior work;
- respect privacy, intellectual property, and responsible disclosure;
- help new contributors understand the project conventions;
- avoid harassment, discrimination, intimidation, and deliberately disruptive
  behavior.

## Scientific integrity

Contributors must not fabricate results, hide known limitations, or present
idealized simulations as complete physical or security guarantees. Numerical
claims should include enough information to reproduce the relevant result.

## Scope

This code applies to repositories, issue trackers, pull requests,
documentation, community discussions, project events, and private interactions
that directly concern iQuant4 participation.

## Reporting

Security vulnerabilities should follow `SECURITY.md`. Other conduct concerns
should be reported privately to the project maintainer. Reports will be handled
as confidentially and fairly as practical. Project maintainers may remove
content, restrict participation, or take other proportionate action when this
code is violated.
